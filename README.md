
# Estudo do Paradigma de Orientação a Objetos em Java

Bem-vindo ao repositório de estudos sobre o Paradigma de Orientação a Objetos (POO) utilizando a linguagem Java!

## 📌 Sobre o Projeto

Este repositório foi criado para documentar e compartilhar minha jornada de aprendizado sobre os conceitos fundamentais e avançados de Orientação a Objetos em Java. Aqui você encontrará:

- Exemplos práticos dos pilares do POO
- Implementações de conceitos avançados
- Exercícios resolvidos
- Projetos completos demonstrando a aplicação do paradigma

## 🧩 Pilares da POO

Os principais conceitos abordados incluem:

1. **Abstração** - Modelagem de entidades do mundo real como classes
2. **Encapsulamento** - Proteção dos dados e comportamentos internos
3. **Herança** - Reutilização e extensão de código
4. **Polimorfismo** - Múltiplas formas para um mesmo método
